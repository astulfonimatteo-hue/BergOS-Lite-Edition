# BergOS Lite Edition

**BergOS Lite** is a high-performance, lightweight edition tailored for older 64-bit computers, laptops with low memory, and systems requiring minimal background resource usage.

Built on an Ubuntu LTS base with the **XFCE** desktop environment, BergOS Lite preserves full modern software compatibility while delivering speed, efficiency, and system responsiveness.

---

## Key Features

- **Lightweight & Fast:** Powered by XFCE for maximum responsiveness and minimal RAM consumption.
- **Reduced Background Services:** Trimmed system startup services to ensure low CPU and memory footprints.
- **Graphical Installation:** Uses the Calamares installer for a quick and effortless setup.
- **Full 64-bit Compatibility:** Access to the full repository ecosystem, Flatpak support, and modern web browsers.
- **Familiar Interface:** A clean, traditional desktop layout that is easy to navigate.

---

## Technical Specifications

- **Architecture:** 64-bit (`x86_64`)
- **Base System:** Xubuntu / Ubuntu LTS
- **Desktop Environment:** XFCE
- **Installer:** Calamares
- **Display Manager:** LightDM
- **Display Server:** X11
- **Package Management:** APT, Flatpak (optional)

---

## Minimum System Requirements

- **Processor:** 64-bit Single/Dual-Core CPU (1.5 GHz)
- **RAM:** 2 GB minimum (4 GB recommended)
- **Storage:** 15 GB available disk space
- **Graphics:** Any VGA capable graphics adapter
